A single spec line — size, units, location, building type, machines, deliverables. Stack them to form the specs panel the brief requires on every project.

```jsx
<SpecRow label="Size" value="2,450 sq ft" />
<SpecRow label="Building type" value="Multifamily" />
<SpecRow label="Delivered" value="Model · BOM · CSV · Permit set" />
```

Use `inverse` inside a dark ModelStage. Values stay fragments — never write a sentence in the value slot.
