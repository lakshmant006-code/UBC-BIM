Opens every section. The eyebrow + accent rule is the system's most repeated motif.

```jsx
<SectionHeading eyebrow="Service 04" title="MEP detailing and clash detection"
  standfirst="We run MEP against the framing model and report every clash before anything is cut."
  action={<Button variant="ghost">All services</Button>} />
```

Sizes `sm|md|lg|xl`; `xl` is display scale for hero use only. `inverse` on dark stages.
