Capability tag for machines, software, deliverables and building type — the brief's "capability tags" on every project.

```jsx
<Tag>Light-gauge steel</Tag>
<Tag tone="steel">Revit</Tag>
<Tag tone="danger" dot>3 clashes</Tag>
```

Tones: `neutral | accent | steel | ok | danger | inverse`. `mono={false}` for sentence-case content tags. Tags and StickyQuote are the only pill-radius elements in the system.
